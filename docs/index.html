mspsql

Version: __MSPSQL_VERSION__

mspsql is a Kubernetes operator for Patroni PostgreSQL across multiple isolated clusters.

Architecture

PartRuns onPurpose
Hub controllerManagement clusterOwns CRDs, plans desired state, serves registration bundles.
Site agentEach database clusterApplies signed plans locally. The hub does not write into target clusters.
WireGuard gatewayHub and sitesPrivate control-plane transport for agent registration and plan delivery.
TUN device pluginClusters using WireGuard podsProvides /dev/net/tun to gateway and agent workloads.

Read First

  1. Install prerequisites and manifests with Install.
  2. Review CRDs before writing manifests: CRD Reference.
  3. Start from Examples; change names, StorageClasses, issuers, Vault paths, and images.
  4. Use Operations for status, backup, restore, upgrades, and failure checks.

mspsql manages PostgreSQL control-plane resources. Network design, Vault policy, cert-manager issuers, object storage, StorageClasses, DNS, and database SLOs remain platform responsibilities.
