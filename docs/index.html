mspsql

Current release: __MSPSQL_VERSION__

mspsql is a hub-and-agent Kubernetes operator for Patroni-managed PostgreSQL across isolated clusters.

What It Does

  • Runs hub controllers in a management cluster.
  • Registers target clusters as SiteRegistration resources.
  • Deploys local site agents that perform all target-cluster Kubernetes writes.
  • Uses signed desired-state plans over WireGuard plus mTLS gRPC.
  • Manages etcd, PostgreSQL, Patroni, Pgpool, pgBackRest, TLS, backup, restore, and upgrades.

First Read

  1. Read Design before production use.
  2. Install prerequisites from Install.
  3. Create SiteRegistration objects and apply each generated registration bundle to its target cluster.
  4. Create a MultiSitePostgres instance only after all required sites are Connected.

This operator intentionally does not proxy database traffic. Data-plane routing, DNS, storage, Vault, cert-manager, MetalLB, and PostgreSQL SLOs remain platform responsibilities.
