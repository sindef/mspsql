CRD Reference

API group: multisite-postgres.dev/v1alpha1. Hub-scoped workload CRs are namespaced unless noted.

SiteRegistration

Scope: cluster. Short name: site. Declares one target cluster and its allowed platform policy.

Spec fieldRequiredDescription
displayNameNoHuman-readable site label.
revokedNoStops trust for the site. Does not delete target workloads.
permittedStorageClasses.etcd[]YesStorageClasses allowed for etcd PVCs.
permittedStorageClasses.postgres[]YesStorageClasses allowed for PostgreSQL PVCs.
permittedStorageClasses.restoreWorkspace[]NoStorageClasses allowed for restore workspace PVCs.
storageRollbackPolicies[]NoMajor-upgrade rollback method per StorageClass. Strategy is VolumeSnapshot or PVCClone.
permittedIssuersYesAllowed cert-manager issuers for etcd, PostgreSQL, Pgpool, and backup certificates.
metallbAddressPools[]NoAllowed MetalLB address pools for LoadBalancer Services.
Status fieldDescription
phaseRegistration state. Wait for Connected before using the site.
registrationURLTemporary URL for the target-cluster registration bundle.
agentVersionConnected site-agent version.
discoveredStorageClassesStorage inventory reported by the site.
conditionsDetailed readiness, policy, and trust failures.

PostgresRestore

Point-in-time restore into a new target instance. In-place restore is not supported.

Spec fieldRequiredDescription
sourceInstanceRefYesExisting source instance with backups.
targetInstanceRefYesNew instance name to create from backup.
targetTimeYesRFC3339 recovery target time.
backupSetNoSpecific backup set. Leave empty for automatic selection.
restoreTopology.sites[]NoOverride target topology. Same shape as MultiSitePostgres.spec.sites.
targetBackupNoBackup policy for the restored instance.

PostgresUpgrade

Durable upgrade operation for one instance. Only one restore or upgrade operation should run per instance.

Rules

  • Apply CRs to the hub cluster, not directly to site clusters.
  • Wait on conditions, not only resource existence.
  • Use Retain unless destructive cleanup is intentional and reviewed.
  • Pin images. Do not use mutable tags for production manifests.
