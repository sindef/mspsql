API

API group: multisite-postgres.dev/v1alpha1.

SiteRegistration

Cluster-scoped target-cluster identity and platform policy.

FieldUse
spec.permittedStorageClassesAllowed StorageClasses for etcd, PostgreSQL, and restore workspace PVCs.
spec.storageRollbackPoliciesRequired for major upgrades; declares snapshot or PVC clone rollback support.
spec.permittedIssuersAllowed cert-manager Issuer or ClusterIssuer references.
spec.metallbAddressPoolsAllowed LoadBalancer address pools.
spec.revokedIrreversible control-plane revocation. Workloads are not deleted.

MultiSitePostgres

Desired topology for one PostgreSQL installation.

FieldUse
spec.deletionPolicyRetain by default. Delete deletes namespaces/PVCs after backup checks.
spec.postgresPostgreSQL major version, image, parameters, and synchronous standby count.
spec.credentialsVault references for PostgreSQL and Pgpool credentials. Values never pass through hub CRs.
spec.sitesData and witness sites, storage, LoadBalancer pool, Vault auth, and certificate issuers.
spec.backupS3 pgBackRest repository, schedules, and retention.
spec.tdeOptional pg_tde Vault provider identity.

PostgresDatabase

Non-destructive database, schema, role, grant, and quota reconciliation.

Deleting a declaration with deletionPolicy: Retain does not drop databases, schemas, or roles.

PostgresUser

Login role, memberships, Vault-backed password, and role quotas.

Password values stay site-local and must not appear in manifests, logs, or arguments.

PostgresRestore

Point-in-time restore into a new target instance. In-place restore is forbidden.

PostgresUpgrade

Durable minor or major upgrade operation.

Major upgrades require a pinned upgradeImage, rollback policy, and benchmark evidence.

Conditions

Readiness is condition-based. Use kubectl wait on Ready and inspect failed conditions before touching child resources.
