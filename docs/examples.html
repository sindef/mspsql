Apply Order

  1. Platform installs cert-manager, MetalLB, Vault policy, object storage, and StorageClasses.
  2. Hub operator is installed.
  3. SiteRegistration resources are created in the hub.
  4. Registration bundles are applied to target clusters.
  5. MultiSitePostgres is created after sites are connected.
  6. Tenant database/user CRs are created after the instance is ready.
