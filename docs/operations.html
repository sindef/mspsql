Backups

  • WAL archiving is continuous when backup is configured.
  • Full, differential, and incremental schedules are cron strings.
  • Repository credentials and cipher passphrases come from Vault.
  • Repository prefix must be unique per instance.

Restore

  • Restore creates a new instance.
  • The source instance is not modified.
  • Recovery must pass acceptance before Pgpool is exposed.

Upgrades

  • Only one upgrade or restore may target an instance at a time.
  • Minor upgrades roll replicas first and use Patroni switchover.
  • Major upgrades require backup, rollback storage, benchmark evidence, and a pinned upgrade image.
  • Automatic rollback is only safe before Pgpool write service is restored.

Deletion

  • Retain removes active workloads and LoadBalancers but keeps namespaces, PVCs, and backups.
  • Delete deletes target namespaces and PVCs after backup checks.
  • Unreachable sites block finalization unless an administrator explicitly force-orphans.

Do Not

  • Do not edit managed child resources to perform planned changes. Change the CR.
  • Do not reuse backup prefixes or TDE key paths across independent instances.
  • Do not put Secret values in CRs, plan payloads, Git, or tickets.
  • Do not assume pod Ready means PostgreSQL is writable. Use conditions and acceptance checks.
