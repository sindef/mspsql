Install

Install the hub into a dedicated management cluster. Install site agents only through registration bundles generated by the hub.

Prerequisites

  • Kubernetes clusters with Secret encryption at rest enabled.
  • cert-manager installed on hub and site clusters.
  • MetalLB or another LoadBalancer implementation that supports stable UDP and TCP Services.
  • ExternalDNS for the hub WireGuard hostname.
  • Vault reachable from each site, using Kubernetes auth.
  • S3-compatible object storage for pgBackRest.
  • StorageClasses explicitly approved per site.

Install Hub

git clone https://github.com/sindef/mspsql.git
cd mspsql
git checkout v__MSPSQL_VERSION__

make install
make deploy IMG=ghcr.io/sindef/mspsql:__MSPSQL_VERSION__

Set Released Images

Before applying rendered manifests, pin every runtime image:

cd config/manager
kustomize edit set image controller=ghcr.io/sindef/mspsql:__MSPSQL_VERSION__

cd ../agent
kustomize edit set image site-agent=ghcr.io/sindef/mspsql-agent:__MSPSQL_VERSION__
kustomize edit set image wireguard=ghcr.io/sindef/mspsql-wireguard:__MSPSQL_VERSION__

cd ../gateway
kustomize edit set image lease-gate=ghcr.io/sindef/mspsql-gateway:__MSPSQL_VERSION__
kustomize edit set image wireguard=ghcr.io/sindef/mspsql-wireguard:__MSPSQL_VERSION__

cd ../tun-device-plugin
kustomize edit set image tun-device-plugin=ghcr.io/sindef/mspsql-tun-device-plugin:__MSPSQL_VERSION__

Register Sites

  1. Create one SiteRegistration per target cluster.
  2. Wait for .status.registrationURL.
  3. Apply that URL to the target cluster.
  4. Wait for status.phase=Connected.
kubectl apply -f examples/site-registration.yaml
kubectl get siteregistration
kubectl apply -f 'https://hub.example.com/<token>/registration.yaml'

Create an Instance

kubectl create namespace database-platform
kubectl apply -f examples/multisite-postgres.yaml
kubectl -n database-platform wait multisitepostgres/orders \
  --for=condition=Ready --timeout=30m
